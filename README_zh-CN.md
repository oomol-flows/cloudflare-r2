# Cloudflare R2 云端上传

一个为 OOMOL 工作流设计的可靠、高效的文件上传解决方案,支持无缝文件传输到云存储,并自动生成预签名 URL。

## 概述

这个 OOMOL 包提供了一个强大的文件上传模块,能够处理分块文件上传到云存储。它通过分片上传自动管理大文件传输,提供实时进度跟踪,并生成有时效限制的预签名 URL 以确保文件访问安全。

## 功能特性

- **分块上传支持**: 自动将大文件分割成可管理的块以实现可靠上传
- **进度跟踪**: 实时上传进度报告,与 OOMOL 进度系统集成
- **自动重试**: 内置失败分块上传重试机制(每个分块最多重试 3 次)
- **并行处理**: 同时上传多个分块以获得最佳性能
- **预签名 URL 生成**: 自动生成安全的、有时效限制的访问 URL(有效期 24 小时)
- **错误处理**: 全面的错误处理和详细的错误消息

## 功能模块

### 上传文件到云端

**模块名称**: `upload-to-cloudflare`

将本地文件上传到云存储并返回用于访问文件的预签名 URL。

#### 输入参数

- **file** (字符串, 必填): 要上传到云存储的本地文件路径
  - 支持文件选择器小部件,方便选择文件
  - 接受任何文件类型和大小

#### 输出参数

- **remote_url** (字符串): 用于访问已上传文件的预签名 URL
  - 从生成时起有效期为 24 小时
  - 可直接用于下载或分享文件
  - 格式: 指向云存储位置的 HTTPS URL

#### 工作原理

1. **初始化**: 模块分析文件大小并向云服务请求上传会话
2. **分块**: 大文件自动分割成优化的块(分块大小由服务器确定)
3. **上传**: 并行上传分块,失败时自动重试
4. **完成**: 所有分块成功上传后,生成预签名 URL
5. **进度**: 持续报告上传进度(0-100%)

## 使用示例

### 在工作流中使用

1. 将"上传文件到云端"模块添加到您的工作流中
2. 连接文件路径(可以来自文件选择器或其他模块的输出)
3. 模块将上传文件并输出预签名 URL
4. 在后续模块中使用预签名 URL(例如分享、处理或显示)

### 常见用例

- **文件分享**: 上传文件并与他人分享预签名 URL
- **数据处理管道**: 在使用其他服务处理文件之前上传输入文件
- **备份解决方案**: 自动将文件备份到云存储
- **媒体托管**: 为 Web 应用程序上传图像、视频或音频文件
- **文档管理**: 通过预签名 URL 存储和检索文档

## 技术细节

### 架构设计

上传过程采用三阶段架构:

1. **初始化阶段**:
   - 向服务器发送文件元数据(扩展名和大小)
   - 接收上传配置(upload_id、part_size、total_parts、presigned_urls)

2. **上传阶段**:
   - 根据服务器提供的 part_size 将文件分割成块
   - 使用预签名 URL 并行上传块
   - 实施指数退避重试策略(延迟 1 秒、2 秒、3 秒)
   - 每个分块成功上传后报告进度

3. **完成阶段**:
   - 使用 upload_id 请求最终预签名 URL
   - 返回有效期为 24 小时的 URL

### API 端点

- **初始化上传**: `POST https://llm.oomol.com/api/tasks/files/remote-cache/init`
- **获取最终 URL**: `GET https://llm.oomol.com/api/tasks/files/remote-cache/{upload_id}/url`
- **分块上传**: 直接 PUT 请求到预签名 URL

### 身份验证

模块自动使用 OOMOL 令牌进行身份验证。无需手动配置 API 密钥。

### 性能优化

- 并行分块上传最大化带宽利用率
- 根据文件大小自动调整分块大小
- 重试机制防止网络问题导致的失败
- 进度报告提供用户反馈

### 错误处理

模块处理各种错误场景:

- 文件未找到错误
- 网络连接问题
- 服务器错误(带有描述性状态代码)
- 缺失预签名 URL
- 上传超时失败

所有错误都包含详细消息以便故障排除。

## 安装

此包可在 OOMOL 包注册表中获得。使用以下命令安装:

```bash
# 搜索包
oomol search cloudflare-r2

# 安装包
oomol install cloudflare-r2

# 添加到工作空间依赖
oomol use cloudflare-r2
```

## 系统要求

- Node.js 运行时(由 OOMOL 自动配置)
- 具有令牌身份验证的 OOMOL 平台
- 访问云存储的互联网连接

## 依赖项

所有依赖项通过 npm 自动管理:

- `@oomol/types`: OOMOL 类型定义和上下文 API
- Node.js 内置模块: `fs`、`path`

## 配置

无需手动配置。模块自动:

- 从 OOMOL 上下文检索身份验证令牌
- 从服务器确定最佳分块大小
- 自动处理所有上传参数

## 限制

- 预签名 URL 在 24 小时后过期
- 上传速度取决于网络带宽
- 大文件可能需要时间上传(会报告进度)
